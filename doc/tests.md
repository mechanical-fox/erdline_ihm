

# Tests Manuels


Ceci est une suite de tests manuels, afin de vérifier que le logiciel fonctionne tel qu'attendu.
Le but est de dérifier lors de mises à jours futures, que le logiciel fonctionne correctement après l'ajout
de la nouvelle fonctionnalité. Il s'agit ici d'une liste de test sommaire, afin de pouvoir faire une vérification
rapide sur les fonctionnalités les plus importantes.
